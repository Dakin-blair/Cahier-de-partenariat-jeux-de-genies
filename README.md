# 📖 À propos

Ce dépôt contient l'ensemble des fichiers nécessaires à la conception, à la révision et à la publication du **cahier de partenariat** destiné aux entreprises et organisations souhaitant soutenir la délégation de l'Université du Québec en Outaouais aux Jeux de Génie 2027.

Le cahier présente notamment :

- la mission de la délégation;
- les possibilités de partenariat;
- les différentes visibilités offertes;
- les besoins financiers;
- les informations de contact.

L'objectif est de conserver un historique clair des modifications tout en facilitant la collaboration entre les responsables.

# 🚀 Objectifs

- Maintenir une version officielle du cahier.
- Faciliter la collaboration entre les responsables.
- Conserver l'historique des versions.
- Préparer les documents destinés aux partenaires.
- Centraliser les ressources graphiques.

# 🤝 Contribution

Les contributions sont réservées aux membres de la délégation.

Avant toute modification importante :

1. créer une branche;
2. effectuer les changements;
3. ouvrir une Pull Request;
4. faire réviser les modifications.

---

# 🌿 Convention Git


## Commits

```

```

Exemple :

```

```

Une synapse est le point où une idée devient action.
